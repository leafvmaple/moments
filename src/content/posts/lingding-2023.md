[去年 4 月那一次](/posts/lingding-2022) 是疫情第三年刚解封那一波 —— 这次已经全放开了、还是选了同一座岛。同一艘船、同一片海岸、同一座弯月雕塑、同一座翡翠湖（这次拍下石碑、补一个学名「矿石湖」）—— 不同的同伴、早一个月的春天、几处那次没去过的地方。

## 上岛 · 3/4

### 再访 · 抵岛靠岸

[去年是 黄昏从「新海洋」船下来到岛](/posts/lingding-2022)；今年同一艘船、上午十一点上岸。

![新海洋 · 抵岛靠岸](/images/lingding-2023/20230304_105904.jpg)

蓝白船身 + 「新海洋 XIN HAIYANG 珠海 ZHU HAI」字样 + 一排黑色防撞旧轮胎 + 拱门入口栏杆 + 几个游客拉着行李正下船。去年下午回程时码头空、海风咸；今年上午抵达、人多、太阳偏白、海水偏蓝灰。

### 海岸礁石 · 同一片海

下午走到岛南边的海岸。

![南湾海岸 · 礁石 + 沙滩 + 远船](/images/lingding-2023/20230304_154030.jpg)

跟 [去年那片礁石宽幅](/posts/lingding-2022) 是同一段海岸 —— 但视角更近、季节更早。前景一棵棕榈把画面切成两半、右下角一个穿粉红裙的小女孩正比着手势让同伴给她拍照、左边一队游客慢慢走过来。海是浅蓝、礁石是橙红色的花岗岩、海浪打湿的部分发深。远处依然是 一片渔船 + 远岛剪影 —— 跟去年同框、跟去年同色。

只是这次画面里多了人。

### 弯月雕塑 · 黄昏 + 肥皂泡

往北走到 [去年那座弯月雕塑](/posts/lingding-2022) —— 这次是黄昏。

![弯月雕塑 · 日落 + 肥皂泡 + 双月](/images/lingding-2023/20230304_172123.jpg)

下午光把雕塑表面打成橘色、底座上刻的「**海上生明月 天涯共此时**」终于看清楚了 —— 是去年下午硬光下没注意到的字。这次画面里多了两样：

- **第二座小弯月**：立在主雕塑左侧、形状是个低一截的偏月 —— 原来是个双月组（去年看到的只有右边那个大的）
- **一串肥皂泡**：不知道是谁吹的、漂在画面上方 —— 有一个泡正好经过太阳 + 镜头中间、阳光被弯弯地折一下

左下角一个人坐在礁石上看海、远处一艘船。一切都很慢。

### 海上日落 · 渔船过往

往西走到岛西岸看落日 —— 这边没什么人。

![17:30 · 海面 + 远船 + 浮标](/images/lingding-2023/20230304_173045.jpg)

天空是淡橘色 + 海面铺一层金箔反光、远处一艘大渔船 + 一串红色浮标在水面上画出一条横线。

![17:39 · 西岸度假公寓 + 落日反射](/images/lingding-2023/20230304_173955.jpg)

再往北一点能看到岛西的一片度假公寓 —— 米白坡屋顶 + 一排棕榈站在水边、太阳已经压到楼后面、海面被反光照得发亮 + 前景一段木板伸进水里。

到 18:05、太阳贴海面、一艘小渔船刚好从画面右侧驶过 —— 录了一段 Live Photo。

![18:05 · 海上日落 + 渔船过往 · Live Photo](/images/lingding-2023/20230304_180526.webp)

3 秒循环：渔船从画面中央朝左推开几道白浪 + 太阳落得肉眼可见的快 + 远海几艘大货轮在云层下、一动不动 —— 是这次行程最舍不得只拍静图的一瞬间。

等太阳完全沉到海面下、远海几艘大货轮黑成剪影。

### 海鲜市场 + 海滨广场夜景

天黑以后绕到岛中心的 海鲜市场 —— 这是 [去年那帖](/posts/lingding-2022) 没逛到的一片。

![外伶仃岛海鲜市场 · 大蓝章鱼装置](/images/lingding-2023/20230304_185608.jpg)

入口顶上立着一只巨大的蓝色卡通章鱼 —— 八只触手向四个方向伸开、两只大眼睛看着前方。「外伶仃岛 海鲜市场」绿色招牌 + 「外伶仃岛 旅游公司」小 logo。市场里游客 + 摊位摆满 + 灯火通明 —— 是岛上夜晚最热闹的一处。

出来走到旁边的海滨广场。

![海滨广场夜景 · 远景小山岩岛](/images/lingding-2023/20230304_185609.jpg)

广场椰子树夹道 + 一根国旗杆 + 远处一座小山岩岛（应该是岸边一块巨石、被打灯打成黄色）+ 灯下几只木船停在沙滩上。天还没完全黑、地平线还有一线橘紫色。

### 酒吧 · 长岛冰茶 + 烤肠

晚饭后绕回 [去年中午喝精酿的那家酒吧](/posts/lingding-2022) —— 同一家。

![长岛冰茶 · 玻璃杯 + 藤编桌](/images/lingding-2023/20230304_224423.jpg)

点了一杯长岛冰茶 —— 冰柠片 + 黑色吸管 + 玻璃杯里浅金黄、桌面是编织藤格子。底子是龙舌兰 + 朗姆 + 伏特加 + 金酒 + 君度 + 柠檬汁 + 可乐、调出来颜色像红茶 —— 名字也由此来。喝下去比想象的烈、像是岛上没什么娱乐节目以后、把酒劲集中调进了一杯。

聊到 23:10、加点了一盘烤肠下酒。

![夜宵 · 4 串铁板烤肠](/images/lingding-2023/20230304_231003.jpg)

铁盘上排开 4 串烤肠 + 撒辣椒粉 + 椒盐 + 黑胡椒 —— 表皮焦褐、底下烤出油光、咬下去脆口。这家酒吧白天卖精酿、晚上加几样小吃 —— 是岛上夜里少数还亮着的店。

### 酒店 · 围一桌春卷

11 点多走出酒吧、回酒店路上几个人提议再续一份、外卖叫了几份春卷、过零点围在房间矮桌前一起吃。

![00:34 · 春卷大碗包 · 撒辣椒 + 黑芝麻](/images/lingding-2023/20230305_003428.jpg)

岛上常见的"卷饼包卷饼"风格 —— 一张大春卷皮卷着烤过的薄饼 + 蔬菜 + 火腿肠 + 撒辣椒粉 + 黑芝麻、装在白色纸碗里、筷子一夹就能撕出来吃。比烤肠重口、收尾辣到喝水。

灯关掉之前还在聊明天去矿石湖的路线 —— [跟去年那次 同伴不一样](/posts/lingding-2022)、围桌的人也不一样。一点多睡。

## 离岛 · 3/5

### 翡翠湖 · 学名矿石湖

下午往岛南边走山路、再次走到 [去年那座「翡翠湖」](/posts/lingding-2022)。

![「矿石湖」石碑 + 上山公路](/images/lingding-2023/20230305_133009.jpg)

水泥山路一路上行、两边是花岗岩 + 干燥的山地植被 + 几根路灯杆 + 一面蓝色警示牌。路边立着一块大花岗岩石碑、绿字「矿石湖」刻在石面上。**「翡翠湖」其实是游客叫法、学名是「矿石湖」—— 因为是花岗岩采石场停采的水塘、绿色的水反而是矿物质溶解出来的**。去年也路过这块石碑、没拍下来、就跟着游客叫法写进了 [那帖](/posts/lingding-2022)；这次拍下来、算是补一个学名。

没下到湖边、只在石碑这里拍了一张就继续往山顶走。

### 山顶 · 花岗岩 + 宽幅鸟瞰

继续往山顶爬。

![山中花岗岩 · 仰拍](/images/lingding-2023/20230305_135819.jpg)

仰拍一段山脊 —— 整面花岗岩堆叠 + 灌木 + 蓝天 + 一道光从右上角扫过来。**外伶仃 的花岗岩特别 —— 整块整块圆顶 + 表面有自然风化的卵石质感** —— 是 [去年只从山顶鸟瞰](/posts/lingding-2022) 没注意到的细节。

走到 山顶平台 拍了一张宽幅。

![山顶宽幅 · 海湾 + 远岛 + 通信塔](/images/lingding-2023/20230305_143224.jpg)

超宽幅。左侧两根白色通信卫星塔 + 中央海湾 + 远海一道远岛剪影（**蜘洲岛 + 担杆群岛 北端**）+ 右下角散落几只大花岗岩 + 一道护栏 + 一块蓝色信息牌。跟 [去年那张山顶鸟瞰](/posts/lingding-2022) 是同一处、但下午光更柔、视野更清。

### 红柱亭 + 山腰宽幅

下山途中绕到岛上另一座观海亭 —— 跟 [去年那座八角亭](/posts/lingding-2022) 不同的位置。

![中式六角亭 · 红柱 + 灰瓦](/images/lingding-2023/20230305_152020.jpg)

红柱 + 灰瓦顶 + 木栏杆 + 树丛包围 + 砾石广场地砖 —— 是中式 重檐六角亭（双层屋顶）、立在山腰中段、四面被林子遮着、没风。亭里空、台阶上一道竹影。

往下走几十步、视野又开了。

![山腰宽幅 · 远景南湾港](/images/lingding-2023/20230305_152154.jpg)

宽幅。前景一片山林 + 右下角栈道 + 中段是 南湾港 + 几十只渔船 + 远海远岛 —— 远岛后面那一道模糊海面就是 伶仃洋 西北方向。山腰这个角度比山顶低、但港口的细节多。

### 离岛 · 船「新海洋」

四点多走到码头登船。

![新海洋 · 拱门下侧角](/images/lingding-2023/20230305_164415.jpg)

拱门下视角拍到 「新海洋 XIN HAIYANG」+ 一面「蓝色干线」公司彩色波浪船身。前景是码头的混凝土横梁 + 后景是船舱玻璃 + 几个游客在登船。

两天的 外伶仃 结束了 —— 又坐 同一艘船 回 珠海。
