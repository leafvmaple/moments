壬寅年三月，外伶仃

叶枫影 2022 年 04 月 03 日 #旅行#珠海#外伶仃岛#广东

上岛 · 4/3

出发 · 珠海港的日料午餐

疫情第三年、解封那一波刚出来 —— 找了个广东本地能去的小岛 —— 外伶仃岛（珠海香洲东南 27 海里、万山群岛 东端、距香港 18 海里、属万山海洋保护区）—— 一个 0.95 平方公里的小岛、香洲港 一天两班船出发。

上船前先吃饭。

整桌看是日式套餐 —— 握寿司 + 玉子烧 + 烤鳗鱼 + 寿司卷 + 三文鱼柳 + 味噌汤 + 一壶清酒。下面三道菜按上桌顺序排开：沙律蛋包（蟹籽 + 樱桃番茄 + 紫甘蓝）前菜、铁板烤肉（撒葱花 + 芝麻、底下焦得发黑）主菜、再来焗蟹盖（蟹甲 + 烤芝士 + 蟹籽 + 沙律垫）。份量正好够上船前压一压。

上岛 · 「外伶仃岛」石碑

香洲港到 外伶仃 一小时多船程。坐到岛上 南湾港 已经下午 4 点。

进岛第一眼是一块花岗岩石碑、红字「外伶仃岛」刻在石面、一棵棕榈立在旁边。伶仃洋（珠江口出海口那片海域）的名字来自南宋末年 文天祥 1278 年被元军押解过这片海写下的《过零丁洋》—— 「惶恐滩头说惶恐、零丁洋里叹零丁」。外伶仃岛 位于 伶仃洋 东南边缘、跟那首诗 同名同源。

往酒店方向走的路上看一眼海湾。

沙滩 + 港口 + 一片连续的山脊 —— 山脊那边是 担杆群岛 + 香港离岛的方向。下午光线还硬、海是冬末春初的深蓝。

海岸下午 · 弯月雕塑

往海边走、撞上一座大型雕塑。

立在礁石上、一座白色的「弯月」—— 两个对称的弧形像月亮的两端、中间空、底座上刻着名字 + 落款。背景是海 + 远山 + 一条防鲨网把泳区切成一道直线、海水那时已经偏深。海风从沙滩那一面吹上来、白色雕塑表面被阳光打得发亮 —— 前面几个游客在排队拍照、一对父女在等的间隙转身看了一眼海。

海岸下午 · 八角亭 + 相框 + 礁石

再走几步是一座观海亭。

中式八角亭立在海边巨石上、青瓦顶 + 木栏杆 + 几张石椅。亭旁是一片巨石堆 + 一条木栏栈道往海里伸。上到亭里坐了一会、风比下面大、海浪打石头的声音直接灌进来。坐在石椅上、海面那一片小岛剪影像是剪刀剪过的纸。

下一个打卡点是一块蓝色相框。

蓝色金属相框 + 「I ♥ WAILING DING」红心字样 + 下方刻着坐标「114°03’07”E, 22°10’26”N」—— 透过框能看到南湾港口里几只渔船 + 远处的小山。国内海岛景区这几年都迷上了「坐标 + I LOVE XX」这种打卡相框、地标性 + 易出片 —— 属于过去十年的一档旅游视觉。框前排了几个人、轮到自己也站进去拍了一张。

再绕过一段、是一片连续的花岗岩礁石。

宽幅全景。一片花岗岩礁石伸进海里、上面散着几个钓鱼客 + 一队旅游团游客。远处几座小岛 + 远山。外伶仃 的地形是花岗岩 —— 1980-90 年代曾被开采供给 珠海 + 香港 的建材、停采后留下的岩壁和水塘还在（第二天会看到一个）。

广场

往回走是岛上中心广场。

宽阔的广场地砖 + 一圈棕榈树 + 几辆橙色观光三轮车停在路口候客 —— 餐厅、民宿、码头、便利店都围着广场转。下午光开始斜了、广场上没什么游客、几个穿浅色衣服的中年居民坐在棕榈树下抽烟聊天 —— 是国内常住人口几千人的小渔镇的标准样子。

夜街 + 海滩

晚饭后绕到海边走走。

晚上的海边商业街 + 一盏路灯 + 几家露天餐厅 + 几把折叠太阳伞收起来靠在桌边 + 椰子树投影。岛上人不多、夜风很大。露台几张桌子有人在喝酒 + 有人在看手机 + 一个小孩在椅子上睡着了头歪向妈妈那边。

走到沙滩边、是另一档景象。

沙滩被红色 LED 灯打亮 —— 是夜游加的氛围光、走在上面像踩进一片红色的雾。海面一片黑 + 远处岸上几个黄色亮点 + 一座亭子被打成黄光立在右上礁石上。海风咸咸的、远海是 内伶仃岛 + 香港离岛 在墨蓝色的天空下。站着看了一会、那片红光让人有点不真实 —— 像被打了滤镜的明信片。

离岛 · 4/4

翡翠湖 · 废采石场水塘

第二天早起、坐观光车去岛南边的山里 —— 车送到翡翠湖入口下客、剩下的路自己走。

走到水塘边眼前是一面蓝绿色的水 + 一面阶梯式崖壁 —— 崖壁上能看到一层层水平的开采痕迹、是早年花岗岩采石场停采后留下的；积水成湖、矿物质让水呈现蓝绿色 —— 民间称「翡翠湖」。沙滩是花岗岩粉化的浅黄色沙、踩上去吱吱响。

山公路 + 山顶鸟瞰

从翡翠湖出来沿着山中公路往上爬。

水泥公路在脚下一路弯下去、左右两边是花岗岩 + 干燥的山地植被 + 几根路灯杆。远处是海湾 + 远海岛屿剪影。岛上的公路就这一条主路绕环 —— 步行也是这条路。

走了 40 多分钟到山顶。

宽幅全景：山下是 南湾港 + 几十只渔船 + 一片白色防波堤、海面 + 远处几座岛 + 一道公路顺山岭蜿蜒下来 —— 整座 0.95 平方公里的岛、从这里一眼看完。

铜钟 + 一杯精酿

山顶往下也是步行。一路走到一座大铜钟附近 —— 从翡翠湖算起走了快一个半小时、脚有点软。

黄色钟楼下挂一只青铜钟、钟身一道红绑带、旁边一面石壁刻着繁体行书的诗文 —— 外伶仃岛 的「石刻」文化、历代来岛的文人留下的诗刻 + 跟「文天祥过此」的传统呼应。前面摆着一张桌子 + 一把椅子 + 一只可以击钟的木锤。试着敲了一下、声音穿过山谷传出去 —— 比想象的更响。

在铜钟附近上了观光车、坐回村里。午饭找了一家精酿馆。

一杯接近满杯的精酿 —— 杯身一圈细小泡沫 + 金黄酒液 + 木质竹托盘 + 印着卡通插画的菜单。店里几张桌子、几个戴帽子的游客在远处聊天。酒是一款比利时小麦白啤 —— 苦得轻、入口偏柑橘、收尾干净。临走前的一杯。

最后一眼海岸

离岛前码头边等船、看最后一眼。

蓝绿色的海水 + 礁石堆 + 远处礁岸上立着一座白色小塔（航标灯）+ 一道护栏顺着海边延伸。等船的有几十个人、都背着包裹 —— 大部分游客都是周末两天的、跟自己路径差不多。海风又开始硬起来、有人开始穿外套。船一鸣笛、广播喊登船、人群往栈桥那边集中。

回程船「新海洋」+ 珠海 skyline

一小时多回到 珠海香洲港。

下船的瞬间回头拍了一张 —— 蓝白船身写着「新海洋 XIN HAIYANG」+ 一面国旗 + 旁边一艘黄黑相间的工程船。远处是 珠海香洲 的高层 skyline 一字排开、傍晚的天是橙黄色 + 落日把楼群染成剪影。

回程 · 4/4 夜

珠海 · 小龙虾

回程的路上跟同行几个朋友约了一桌小龙虾。

一桌摆开：清蒸 + 麻辣 + 蒜蓉 三种做法、配几碟酱汁 + 一只玻璃杯里浅黄色的什么酒。一艘船两天、登过岛 + 看过翡翠湖 + 喝过精酿 + 路过 1278 年那首诗写过的海 —— 收尾配的是「珠海宵夜」最普通的一档。

桌子的边角是同行人的手 —— 没拍到脸、但是夹小龙虾的那一刻很真。
